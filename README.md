# History through coins

An interactive map of the ancient world from 650 BC to AD 1204, told through its gold coins: borders by year, wars and battles, mints, illustrated stories and lessons.

**Live:** https://escargot-studio.github.io/history-through-coins/ (preview, not yet announced)

Companion to the [Gold Coin Catalogue](https://escargot-studio.github.io/gold-coin-catalogue/), where each coin on the map has its own card.
